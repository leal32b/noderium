Patterns are how the [components](/design/components/) compose into coherent screens.
Reuse a pattern before inventing a new layout.

| Pattern | Where it applies |
| --- | --- |
| Page headers | A consistent title + actions row at the top of each page. |
| Empty states | First-run and zero-result screens that point to the next action. |
| Autosave | Debounced save with quiet, non-blocking feedback (the editor). |
| Tooltips | Concise hints on icon-only controls (e.g. the collapsed sidebar). |
| Focus rings | A consistent, token-driven focus indicator on every interactive element. |

The throughline is the [principles](/design/principles/): coherence, simplicity, and a
keyboard-first, accessible default.
