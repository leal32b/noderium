Export produces a **deterministic** `.md` file per note (atomic = a file; journal = one
file per day), with frontmatter, stable `^block-ids`, and `[[wikilinks]]` preserved.
Anti-lock-in is a core principle — export is always available.

See the [export format](/architecture/data-model/) for the exact structure.
