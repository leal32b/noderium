Spaced repetition is the **retain** end of the workflow: turn a note or block into a
card (whole-note or cloze), then work the **due queue**. Grade each card `again` /
`hard` / `good` / `easy` and FSRS schedules the next review.

See [How spaced repetition works](/how-it-works/spaced-repetition/) for the FSRS model.
