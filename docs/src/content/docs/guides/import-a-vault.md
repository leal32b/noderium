Noderium imports Markdown with frontmatter and `[[wikilinks]]`, targeting **Obsidian**
vaults ([ADR-015](/architecture/adr/adr-015-import-obsidian-first/)). A programmatic
path (`import_markdown`) works today; a GUI vault picker is planned. Logseq import is
deferred.

See [Export to Markdown](/guides/export-to-markdown/) for the round trip.
