Search is **100% local** and instant. Press **⌘K** (Ctrl+K) to open the command
palette and search, or use the search surface directly. Today's search is lexical
(FTS5); semantic search is planned.

See [How search works](/how-it-works/search/) for the lexical/semantic/RRF design.
