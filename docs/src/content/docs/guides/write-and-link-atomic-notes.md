Atomic notes are the **distill** end of the workflow: small, single-idea notes
connected with `[[wikilinks]]`. Every link is bidirectional — the target note shows a
**backlinks** pane listing what points to it.

See [CRDT as source of truth](/how-it-works/crdt-source-of-truth/) for how links are
indexed from the editor.
